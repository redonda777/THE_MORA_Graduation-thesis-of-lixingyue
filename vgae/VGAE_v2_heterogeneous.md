## 1. VGAE 核心原理

### 1.1 目标

将异构图结构中的每个节点（版本、章节、句子）压缩为低维向量（128维），使得：
- 在原图中关系近的节点，在向量空间中距离也近
- 版本节点直接编码该版本所有文本内容的统计特征
- 章节节点编码该章节的局部变异模式
- 句子节点编码最细粒度的文本差异
- 无需人工标签，属于**无监督学习**

### 1.2 整体架构：编码器 + 解码器

**编码器（Encoder）**
- 输入：整张异构图的结构信息和节点初始特征
- 输出：每个节点的低维向量表示——但不是单一向量，而是一个**高斯分布**
- 具体输出：均值向量 mu 和对数方差向量 logvar
- 使用**图卷积网络（GCN）**作为编码器，聚合邻居信息
- GCN 同时处理三种边类型：层级包含边（版本→章节、章节→句子）和句子相似性边

**解码器（Decoder）**
- 输入：编码器输出的向量（采样后）
- 输出：重构的邻接矩阵
- 计算方式：两个节点的向量做点积，通过sigmoid输出"应该存在边的概率"

### 1.3 变分推断的关键作用

直接学习确定性向量容易过拟合，尤其是图数据规模小的情况下。引入概率分布后：
- 模型被迫学习**平滑的、有结构的隐空间**
- 通过**重参数化技巧**（reparameterization trick）保持梯度可传播：
  ```
  z = mu + sigma * epsilon，其中 epsilon ~ N(0, I)
  ```

**损失函数组成：**
1. **重构损失（Reconstruction Loss）**：二元交叉熵，衡量解码器输出与真实邻接矩阵的差异
2. **KL 散度（KL Divergence）**：衡量学到的分布与标准正态分布的差距，防止分布坍塌或过度分散

```
Loss = Recon_Loss + beta * KL_Loss
```
其中 beta 为权重系数（通常设为1.0，可调度）。

### 1.4 图卷积网络（GCN）作为编码器

GCN 的核心操作：
1. 每个节点聚合其所有邻居的特征向量（通常取加权平均）
2. 与自身特征结合
3. 通过可学习的权重矩阵做线性变换
4. 过激活函数（ReLU）

**异构图中的消息传递：**
- 版本节点聚合其所有章节的特征（通过层级边）
- 章节节点聚合其所属版本的上层信号 + 下属所有句子的聚合特征
- 句子节点聚合其所属章节的上层信号 + 跨版本相似句子的特征

**层数影响：**
- 一层GCN：节点感知一阶邻居
- 两层GCN：版本节点可感知到"版本→章节→句子→相似句子→对方章节→对方版本"的完整链路
- 层数过多 → **过度平滑（Over-smoothing）**：所有节点特征趋于同质化

### 1.5 训练与推理的区别

训练阶段从分布中采样向量给解码器，计算重构损失和KL散度，反向传播。推理阶段直接使用均值向量 mu 作为节点的最终表示，不再采样。

### 1.6 为什么选 VGAE 而非其他方法

| 方法 | 优点 | 缺点 |
|------|------|------|
| DeepWalk / Node2Vec | 简单快速 | 只利用拓扑结构，无法融合节点文本特征；无法处理异构图 |
| GCN（有监督） | 结构特征强 | 需要节点标签，不适合无标签场景 |
| **VGAE** | **无监督**；基于GCN可融合结构和特征；学到概率分布，隐空间更平滑；天然支持异构图（版本+章节+句子统一编码） | 计算复杂度较高 |

### 1.7 直觉理解

想象把整张异构图摊平成一张巨大的多层网。版本节点是网的最顶层锚点，章节节点是中间层骨架，句子节点是最底层的网结。VGAE 给每个网结发一个手电筒（向量），要求通过层级骨架相连的网结光柱对齐，通过相似性边相连的网结光柱重叠。编码器决定手电筒的朝向和散射范围，解码器根据看到的光斑重叠程度猜测原来的网是怎么连的。训练就是让猜测越来越准，同时不让光柱乱散射。

## 2. 异构统一图结构设计

### 2.1 核心设计原则

本方案的核心突破是**将版本、章节、句子作为独立节点统一编码**，而非像旧方案那样仅编码句子节点、让版本和章节成为隐式聚合的虚拟概念。

**两种数据源融合：**

| 数据源 | 提供内容 | 节点类型 | 边类型 |
|--------|---------|---------|--------|
| `mora_v4.1_0406.json` | 版本-章节-句子的层级树 | 版本节点、章节节点、句子节点 | 层级包含边（版本→章节、章节→句子） |
| `sentence_edges.json` | 句子-句子的编辑距离 | 句子节点（已存在） | 相似性边（句子↔句子） |

### 2.2 节点类型与标识

| 节点类型 | 原始ID格式 | 全局ID格式 | 元信息 |
|----------|-----------|-----------|--------|
| 版本节点 | `hj`, `gd`, ... | `version_{name}` | `version`, `index` |
| 章节节点 | Chapter 0, Chapter 1, ... | `chapter_{version}_{chapter_number}` | `version`, `chapter`, `sentence_count` |
| 句子节点 | Sentence 0, Sentence 1, ... | `sent_{version}_{chapter}_{sentence}` | `version`, `chapter`, `sentence`, `text` |

**关键设计：** 三类节点各自拥有独立的可学习向量，版本节点不再是"虚拟聚合"，而是图中的一等公民。

### 2.3 边类型与权重策略

| 边类型 | 连接模式 | 权重 | 是否参与剪枝 | 来源 |
|--------|---------|------|-------------|------|
| `contains_version_chapter` | 版本 → 章节 | 1.0（固定） | 否 | 树状图层级 |
| `contains_chapter_sentence` | 章节 → 句子 | 1.0（固定） | 否 | 树状图层级 |
| `similarity_sentence_sentence` | 句子 ↔ 句子 | 分层计算 | **是** | 编辑距离边 |

**层级边权重固定为1.0的原因：** 层级关系是文献学的结构性事实，不是可选择的相似性信号。版本必须包含其章节，章节必须包含其句子，这种约束不应被削弱。

**相似性边参与剪枝的原因：** 28,549条句子-句子边中存在大量噪声（distance > 0.2），需要通过分层剪枝保留核心信号。

### 2.4 消息传递路径分析

**版本节点如何学到跨版本相似性？**

```
版本A 的向量
  ← 聚合 章节A_0, 章节A_1, ... 的向量
    ← 聚合 句子A_0_0, 句子A_0_1, ... 的向量
      ← 聚合 相似句子B_0_0（通过 similarity 边）的向量
        ← 来自 章节B_0 的向量
          ← 来自 版本B 的向量
```

两层GCN即可覆盖完整路径：版本A → 章节A → 句子A → 相似句子B → 章节B → 版本B。这是异构统一图相比纯句子图的核心优势——版本关系不再是间接推断，而是直接学习。

### 2.5 何时需要额外注入先验知识

如果VGAE输出的版本向量未能反映已知的文献学流传关系（如"版本B是版本A的清代抄本"），可考虑：
- 添加版本-版本边（权重反映确信度）
- 在损失函数中加入对比学习项
- 但这些属于**知识融合（knowledge injection）**，需在论文中明确说明

## 3. 数据源与节点编码

### 3.1 树状图加载（`mora_v4.1_0406.json`）

树状图采用嵌套JSON结构：根节点 → 版本数组 → 章节数组 → 句子数组。

**加载流程：**
1. 遍历根节点的 `children` 数组，识别 `type: "version"` 的节点
2. 对每个版本，遍历其 `children` 数组，识别 `type: "chapter"` 的节点
3. 对每个章节，遍历其 `children` 数组，识别 `type: "sentence"` 的节点
4. 为每个节点分配全局唯一索引（`version_X` → 0, `chapter_hj_0` → 1, ...）
5. 记录层级边：版本索引 → 章节索引，章节索引 → 句子索引

**节点元信息记录：**
- 版本节点：名称、在树中的序号
- 章节节点：所属版本、章节编号、句子数量
- 句子节点：所属版本、章节编号、句子编号、原始文本

### 3.2 节点统计验证

加载完成后应输出节点统计：
- 版本节点数量（预期：多个版本，如 hj, gd, ...）
- 章节节点数量（预期：版本数 × 每版本章节数）
- 句子节点数量（预期：所有版本所有章节句子总数）

若统计异常（如某版本章节缺失、句子编号不连续），需检查树状图完整性。

## 4. 边数据与距离指标

### 4.1 句子-句子边数据结构

```json
{
  "chapter_number": 0,
  "sentence_number": 0,
  "original_text_version": "ba",
  "modified_text_version": "bb",
  "original_text": "####",
  "modified_text": "上德不德",
  "normalized_distance": 0.05
}
```

**关键字段：**
- `original_text_version` 和 `modified_text_version`：用于构建句子节点全局ID
- `chapter_number` 和 `sentence_number`：用于定位句子节点
- `normalized_distance`：剪枝和权重计算的唯一依据

### 4.2 节点ID匹配规则

边数据中的句子节点必须与树状图中的句子节点一一对应：

```python
# 边数据中的原始句子
src_id = f"sent_{edge['original_text_version']}_{edge['chapter_number']}_{edge['sentence_number']}"

# 边数据中的目标句子
tgt_id = f"sent_{edge['modified_text_version']}_{edge['chapter_number']}_{edge['sentence_number']}"

# 在 node_id_map 中查找对应的全局索引
src_idx = node_id_map[src_id]  # 必须存在，否则说明数据不一致
tgt_idx = node_id_map[tgt_id]
```

**数据一致性检查：** 若边数据中的句子在树状图中不存在，应记录并跳过（可能因树状图截断或边数据包含额外版本导致）。

### 4.3 三个距离指标对比

| 指标 | 含义 | 是否适合VGAE |
|------|------|-------------|
| `edit_count` | 原始编辑操作次数（字符级别） | 否 |
| `adjusted_edit_distance` | 经过规则/LLM修正后的编辑代价 | 否（有长度偏差） |
| `normalized_distance` | 修正代价 ÷ 字符数量，归一化到[0,1] | **是** |

**选择 `normalized_distance` 的理由：**
1. 继承了文献学修正（通假字、虚词等代价已降低）
2. 消除了长度偏差（无论句子长短，数值在[0,1]区间内可比）
3. 有界区间方便直接映射为边权重

### 4.4 数据分布特征

```
## normalized_distance (归一化距离)
| 指标 | 值 |
|------|-----|
| 中位数 | 0.0286 |
| 平均值 | 0.125 |
| 最大值 | 1.0 |
| 最小值 | 0.0 |
| 标准差 | 0.193 |
| 下四分位数 (Q1) | 0.0 |
| 上四分位数 (Q3) | 0.2 |
```

**分布解读：**
- 中位数0.0286极低：半数以上句子对近乎相同
- Q3=0.2：75%句子对差异可控
- 标准差0.193相对于平均值0.125非常大：**极度右偏**，大量数据挤在0附近，少量拖出长尾

## 5. 剪枝策略

### 5.1 剪枝范围限定

**仅对句子-句子相似性边执行剪枝**，层级边（版本→章节、章节→句子）不参与剪枝，全部保留。

**原因：** 层级边是结构性约束，不是可选信号；相似性边是统计性信号，存在噪声。

### 5.2 分层剪枝策略

基于 `normalized_distance` 分布特征（Q1=0, Q3=0.2）的四层处理：

#### 第一层：完全相同（distance = 0）
- **占比**：约25%（~7000条）
- **处理**：保留，权重封顶
- **原因**：不同版本的相同句子仍有文献学溯源价值，不可合并节点
- **权重公式**：
  ```python
  weight = 10.0  # 封顶值
  ```

#### 第二层：高度相似（0 < distance <= 0.1）
- **占比**：约25%（~7000条）
- **处理**：全部保留，指数衰减
- **权重公式**：
  ```python
  weight = exp(-distance / 0.05)
  ```
  - distance=0.1时，weight=exp(-2)=0.135
  - distance趋近0时，weight趋近1.0

#### 第三层：中度差异（0.1 < distance <= 0.2）
- **占比**：约25%（~7000条）
- **处理**：**top-3竞争筛选**
- **逻辑**：对每个句子节点，在本层邻居中只保留权重最高的top-3条
- **原因**：避免一个节点被过多弱边稀释，同时保留可能有价值的弱关系

#### 第四层：显著差异（distance > 0.2）
- **占比**：约25%（~7000条）
- **处理**：**全部删除**
- **原因**：内容已显著不同，对亲缘分析无正面贡献

### 5.3 兜底机制：句子节点连通性保障

分层剪枝后，检查**句子节点**的相似性边度数（层级边不计入）。如果句子节点的相似性边度数 < 3：

```python
for each sentence_node:
    if sim_degree < 3:
        # 从已删除的边中，找回 distance 最小的 (3 - sim_degree) 条边补回
        # 或添加自环（权重 0.01，极弱，仅保连通）
```

确保没有句子节点在相似性图中被完全孤立，同时弱连通边的影响力被压制到近乎忽略。

### 5.4 最终边数预估

| 层级 | 原始占比 | 处理 | 预计保留 |
|------|---------|------|---------|
| distance = 0 | ~25% (~7000条) | 全留，权重封顶 | ~7000条 |
| 0 < d <= 0.1 | ~25% (~7000条) | 全留，指数衰减 | ~7000条 |
| 0.1 < d <= 0.2 | ~25% (~7000条) | top-3采样 | ~4000-5000条 |
| d > 0.2 | ~25% (~7000条) | 全删 | 0条 |
| 兜底补回 | - | 孤立节点救急 | <500条 |
| **层级边** | - | 全保留 | ~版本数×章节数 + ~章节数×句子数 |
| **总计** | **28549条相似性边** | | **~16000-18000条相似性边 + 层级边** |

### 5.5 权重映射的完整公式

```python
def compute_weight(distance):
    if distance == 0:
        return 10.0
    elif distance <= 0.1:
        return exp(-distance / 0.05)
    elif distance <= 0.2:
        # 这些边已经过top-3筛选
        return exp(-distance / 0.05)
    else:
        return None  # 已删除
```

## 7. 训练与评估

### 7.1 训练参数调优

| 参数 | 默认值 | 调优建议 |
|------|--------|---------|
| `hidden_dim` | 256 | 数据量小可降至128 |
| `latent_dim` | 128 | 最终向量维度 |
| `num_epochs` | 400 | 观察Loss曲线，收敛后可提前停止 |
| `learning_rate` | 0.005 | Loss震荡则降，收敛慢则升 |
| `kl_weight` | 1.0 | 初期可设为0，后期逐步增至1.0（退火策略） |

### 7.2 分层评估指标

**句子节点评估：**
- **同章句子轮廓系数（Silhouette Score）**：计算所有句子向量的轮廓系数，以章节编号为标签
- 评估标准：> 0.2 可接受，> 0.4 良好
- **t-SNE 可视化**：检查同章句子是否局部聚类

**章节节点评估：**
- **同名章节轮廓系数**：以章节编号为标签，检查跨版本的同名章节是否聚类
- 评估标准：> 0.2 可接受

**版本节点评估：**
- **版本-版本余弦相似度矩阵**：计算所有版本向量两两相似度
- 检查：已知相近的版本对（如抄本关系）相似度是否显著高于无关版本对
- 输出为 `version_similarity_matrix.csv` 供人工验证

## 9. 常见问题与调试

### Q1: 边数据中的句子在树状图中找不到？

**原因：** `sentence_edges.json` 可能包含树状图中未收录的版本或章节。
**解决：** 在 `load_and_prune_similarity_edges` 中增加存在性检查，缺失的边记录并跳过，不报错中断。

### Q2: 版本节点向量无判别力（所有版本相似度接近）？

**原因：**
- GCN层数不足 → 增加层数到3层（注意过度平滑）
- 版本节点初始特征与章节/句子同质化 → 检查节点特征初始化是否区分类型
- 层级边权重过高淹没相似性信号 → 尝试将层级边权重降至0.5

### Q3: 同章句子轮廓系数极低？

**原因：**
- 句子-句子边质量差 → 检查 `normalized_distance` 计算
- 某些章节本身变异剧烈 → 单独分析该章节的distance分布
- 权重映射不当 → 调整 `weight_scale`

### Q4: 训练Loss不下降或发散？

**原因：**
- 学习率过高 → 降至 0.001
- 边权重范围过大 → 检查 `distance_cap` 是否生效
- 图不连通 → 检查兜底机制是否生效

### Q5: t-SNE可视化完全散乱？

**原因：**
- 剪枝过度 → 放宽 `layer3_threshold` 到 0.3
- 节点特征初始化不当 → 尝试接入文本嵌入
- 需要更多训练轮数 → 增至600轮
